# EcoRover Android Application (Universal Release)

## Binary Details
- **Filename**: `EcoRover.apk`
- **Version**: `1.0.0 (Production Build)`
- **Architectures Supported**: `Universal (arm64-v8a, armeabi-v7a, x86_64, x86)`
- **Android Compatibility**: Android 7.0+ (API Level 24 through API Level 34+)
- **Package Name**: `com.ecorover.ecorover_app`

## Installation Instructions (Sideloading)
1. Download or transfer `EcoRover.apk` to your Android smartphone.
2. Open the `.apk` file using your device's **Files** or **Downloads** app.
3. If prompted by Android, enable **"Install unknown apps"** or **"Allow from this source"** for your file manager.
4. Tap **Install** and wait for the installation to complete.
5. Tap **Open** to launch the EcoRover controller.

## Quick Connection Guide
1. Power on the EcoRover robot chassis.
2. On your phone, connect to Wi-Fi:
   - **SSID**: `EcoRover`
   - **Password**: `12345678`
   *(If prompted "Network has no internet access", choose **Always stay connected**).*
3. Launch the **EcoRover** app. Telemetry and live video streaming will activate automatically.
